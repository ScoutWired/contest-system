What you need

  1. Discord application — create one at discord.com/developers/applications. Copy the Application ID (client ID) and Client Secret (OAuth2 tab). Docs: OAuth2.
  2. Bot + server — in the same app: Bot tab → create bot, copy token (keep secret), enable Server Members Intent (Privileged Gateway Intents; intents docs), invite the bot to your server (OAuth2 → URL Generator → scope bot). Bot quick-start.
  3. IDs — in Discord enable Settings → Advanced → Developer Mode, then right-click your server → Copy Server ID, right-click each role → Copy ID. (official guide to finding IDs)
  4. Power Automate (optional) — at make.powerautomate.com create a flow with trigger When an HTTP request is received, copy its HTTP URL. Trigger authentication docs.

Secrets stay on your server: this wizard only tests them live and shows copy-paste .env lines — they are never saved to the database or logs.
